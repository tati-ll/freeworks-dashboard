# FreeWorks Dashboard

Panel de control web para la gestión de proyectos de trabajadores freelance.

## Descripción

FreeWorks Dashboard es una aplicación web desarrollada como MVP para la startup ficticia FreeWorks. Permite gestionar proyectos, entregables, avances, comentarios de clientes, filtros, búsquedas y notificaciones.

## Tecnologías

- Angular
- Django
- Django REST Framework
- SQLite
- Docker
- Git
